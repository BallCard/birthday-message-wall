## 外部依赖与恢复条件

- Node.js 与 npm
- Vercel 项目
- Upstash Redis 实例
- 正确配置的环境变量

仓库不保存线上留言数据、部署账号、真实口令或访问令牌。恢复部署时需要重新创建或关联对应的外部服务。

## 已知维护事项

- 当前依赖中的 `@vercel/kv` 已被上游标记为弃用。现有线上项目继续依赖已迁移到 Upstash 的 Redis 服务；若未来重新部署或继续开发，应先迁移到当前受支持的 Redis 集成，而不是在归档阶段改写数据层。
- 历史设计规格描述的是 Vue 3 方案，最终交付为 React 19；差异已在项目故事中说明，历史文档不再作为实现指南。
