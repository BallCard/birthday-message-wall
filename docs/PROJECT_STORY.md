# 项目故事：生日祝福墙

## 一句话说明

这是一个为单次生日活动制作的全栈留言墙：参与者留下祝福、互送虚拟礼物，并通过互动宠物和庆祝动效形成更有仪式感的线上体验。

## 为什么做

普通群聊里的生日祝福容易被后续消息淹没，也缺少统一展示。这个项目把祝福集中为可浏览、可互动的页面，并允许活动组织者通过一个链接完成分享。

## 关键设计决策

- 采用 Vercel Serverless Functions，让前后端可从同一仓库部署。
- 每条留言独立存储，并用 Redis 有序集合维护时间顺序，避免所有留言挤在一个键里产生并发覆盖。
- 对昵称、内容、头像和礼物类型做服务端校验，并对写入接口限流。
- 把口令保护设计成可选功能；启用时必须显式配置私密口令，不能依赖公开默认值。
- 将视觉生成提示词与最终截图一并保留，让后来者能看到“如何设计”和“最终做成什么”。
